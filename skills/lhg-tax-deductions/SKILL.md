# lhg-tax-deductions：专项附加扣除梳理

> 目标：对照**专项附加扣除的通用框架**，逐项帮用户过一遍"哪项可能适用、佐证材料齐不齐"，
> 输出一份**扣除项清单** + **易漏项提醒**。
>
> 合规声明（本 skill 全程遵守）：
> **政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，
> 具体请咨询专业人士。**

## 1. 何时使用

- `/tax` 主流程跑完收入梳理后 → 接着跑本 skill
- 用户问"专项附加扣除我能填哪几项""今年多了孩子/买了房要不要更新扣除信息"→ 直接跑本 skill
- 用户只想更新某一项（如赡养老人）→ 跑本 skill 的精简版（只过该项）

## 2. 输入与输出

- **输入**：用户家庭与生活状况描述（子女、住房、老人、教育、医疗等）
- **输出**：`扣除项清单.md`（适用项 / 不适用项 / 待确认项三栏）+ 易漏项提醒

## 3. 七项通用框架（只列名称与适用情形，不编具体金额）

以下为公开办事指南中常见的七项框架（名称为通用概念）。
**具体扣除金额、条件细节以当地最新政策为准**，本 skill 不记忆、不编造数字。

| # | 项目 | 适用情形提示 | 常见佐证材料 |
|---|---|---|---|
| 1 | 3 岁以下婴幼儿照护 | 有 3 岁以下子女 | 出生证明、户口本 |
| 2 | 子女教育 | 子女接受学前/学历教育 | 学籍信息、学校证明 |
| 3 | 继续教育 | 学历（学位）继续教育在读；取得职业资格证书当年 | 学籍证明、职业资格证书 |
| 4 | 大病医疗 | 本人/配偶/未成年子女医保目录内大额自付 | 医保结算单、医院票据 |
| 5 | 住房贷款利息 | 首套住房贷款利息支出 | 贷款合同、还款记录 |
| 6 | 住房租金 | 在主要工作城市无自有住房、租房居住 | 租赁合同、租金支付记录 |
| 7 | 赡养老人 | 赡养 60 岁以上父母（或祖父母/外祖父母） | 亲属关系证明 |

## 4. 梳理四步法

### 4.1 第一步：逐项过，不跳项

按上表顺序逐项问用户是否适用。**不许跳项**——七项全过一遍，
漏掉一项可能就是用户少填的一项。

### 4.2 第二步：适用性只标三档

- **适用**：用户情形明确符合 → 进清单
- **不适用**：明确不符合（如无子女、无房贷）→ 记一笔，不再问
- **待确认**：边界情形（如"父母刚满 60 岁""证书今年刚拿到"）→ 进待确认清单，
  并写清"需要确认什么、去哪里确认（个税 App / 当地税务机关）"

### 4.3 第三步：佐证材料打勾

适用项逐项登记佐证材料"有 / 无 / 部分"。
材料不全的项 → 进"易漏项提醒"，提醒用户提前准备。

### 4.4 第四步：政策数字引用纪律（铁律）

1. **默认不写数字**：清单里只写项目名称与适用情形，不写具体扣除金额。
2. **用户追问金额时**：可以引用公开来源，但必须同时写清
   "来源名称 + 发布/核对日期"，并加一句"政策更新快，请以当地最新政策为准"。
3. **不确定的数字**：一律写"请以当地最新政策为准"，不许估算、不许"大概"。
4. **不给筹划建议**：不说"选哪项更划算""怎么组合最省税"——这是红线。

## 5. 易漏项提醒（高频清单）

根据公开办事指南整理的高频易漏情形（框架性提醒，不涉及金额）：

1. **年度确认**：专项附加扣除信息通常需按年度确认/更新，
   有新增变化（新生儿、买房、换城市租房）要及时更新。
2. **继续教育取证当年**：取得职业资格证书的当年别忘了这一项（只提醒"有这一项"，金额查最新政策）。
3. **大病医疗**：医保目录范围内、个人自付累计超过起付线的部分，
   需要留存医保结算单据。
4. **换工作/换城市**：住房租金的城市档、扣缴义务人信息可能变化，需同步更新。
5. **夫妻/兄弟姐妹分摊**：涉及分摊的项目（如赡养老人），先和家人商量好分摊方式再填报，
   本 skill 不提供"怎么分摊更划算"的建议。
6. **其他扣除**：个人养老金、符合条件的商业健康保险、公益捐赠等，
   如有发生也一并记入"其他扣除"栏并留存凭证。

## 6. 扣除项清单模板

```markdown
# 专项附加扣除清单（整理日期：____，未经核验）

## 适用项
| 项目 | 适用情形 | 佐证材料 | 状态 |
|---|---|---|---|
| 子女教育 | 长子在读小学 | 学籍信息 | □有 □无 |

## 不适用项
- 住房贷款利息：无房贷（用户确认）

## 待确认项
- [ ] 赡养老人：父亲今年 12 月满 60 岁，是否本年度适用——待用户在个税 App 确认

## 易漏项提醒
- 年度扣除信息是否已做本年度确认/更新
- ……

## 备注
- 本清单仅做信息整理，不构成税务建议。
- 政策因地域与年份而异，更新快；具体请咨询专业人士。
```

## 7. 反模式（不要这么做）

- ❌ 背出具体扣除金额却不写来源与日期——这是编造政策数字的温床
- ❌ 说"这两项你选 X 更划算"——筹划建议红线
- ❌ 跳过某项不问——七项必须全过一遍
- ❌ 把"待确认"硬判成"适用"——不确定的就写待确认

## 8. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 七项是否全过了一遍？→ 漏项补上。
2. 是否有政策数字没写来源与日期？→ 补上或删掉数字。
3. 是否出现了"更划算/更省税"类表述？→ 删除，这是红线。
4. 易漏项提醒是否给了？→ 没给就补。

如发现本 skill 自身的方法论缺陷，按以下流程反馈：

- **标准冒烟用例**：用"二孩家庭 + 有房贷 + 父母均超 60 岁"走一遍，
  检查七项是否全过、待确认项是否列出、是否零金额编造、是否零筹划建议。
- **一键提 issue**：确认问题后，以 `[QC] <一句话问题>` 为标题、
  正文写清"复现输入 → 错误输出 → 期望输出"，提交到 https://github.com/lhg-plugs/lhg-tax/issues。

## 附录：七项适用情形速查问答

以下为整理时的高频疑问，只给"是否可能适用"的方向性提示，不给结论、不给金额：

1. **孩子今年 9 月刚上小学，子女教育能填吗？**
   → 可能适用，起止月份按官方口径确认，本 skill 只提醒"有这一项"，具体问个税 App。
2. **房贷已经还清，今年还有住房贷款利息吗？**
   → 按"实际发生利息支出"的月份判断，还清后一般不再适用，记"不适用"并注明原因。
3. **在老家有房，在工作城市租房，住房租金能填吗？**
   → 可能适用（关键看"主要工作城市是否有自有住房"），标"待确认"，让用户在官方渠道核对。
4. **父母一方满 60 岁、一方不满，赡养老人怎么填？**
   → 框架上可能适用，标"待确认"，分摊方式由家人商量，本 skill 不给分摊建议。
5. **今年考了个证，继续教育能填吗？**
   → 先确认证书是否在官方认可的职业资格目录内，再标适用/待确认；金额查最新政策。
6. **去年看病自付花了不少，大病医疗能填吗？**
   → 先确认是否"医保目录范围内、个人自付累计超过起付线"，票据留好，标待确认。
7. **3 岁以下婴幼儿照护和子女教育能同时填吗？**
   → 两项是不同项目，按子女年龄分段判断，各自独立标适用性，不替用户做取舍。

以上问答每年都可能因政策调整而变化，回答用户时一律加一句"请以当地最新政策为准"。
