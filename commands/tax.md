# /lhg-tax:tax —— 个人税务整理主流程

用户输入在 `$ARGUMENTS` 中（一句话描述收入与家庭情况，可空，空则逐步询问）。

> 合规声明：**政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。**

## 流程

### 1. 收入构成梳理（加载 `lhg-tax-income`）

按 skill 方法论输出 `收入构成清单.md`：
- 收入分类（工资薪金 / 劳务报酬 / 稿酬 / 特许权使用费 / 经营所得 / 财产类 / 偶然所得）
- 每项注明金额口径（税前/税后）、期间、凭证状态
- 不编数字、不记身份证号与银行卡号

### 2. 专项附加扣除梳理（加载 `lhg-tax-deductions`）

七项逐项过，输出 `扣除项清单.md`（适用 / 不适用 / 待确认三栏）：
- 3 岁以下婴幼儿照护、子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人
- 凡引用政策金额必须同时写清来源与核对日期，否则写"请以当地最新政策为准"

### 3. 易漏项提醒

- 年度扣除信息确认/更新、继续教育取证当年、大病医疗票据、换工作换城市、家属分摊商量、个人养老金/商业健康保险/公益捐赠

### 4. 申报材料 checklist（加载 `lhg-tax-checklist`）

输出 `申报 checklist.md`：材料四类（身份基础 / 收入凭证 / 扣除凭证 / 申报辅助）
+ 时间节点（加"以当年官方公告为准"）+ 办理渠道 + 提交前五问。

### 5. 自查（加载 `lhg-tax-audit`）

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/tax_audit.py --target <清单目录> --format text
```

blocker 清零才交付；为清零改规则算作弊，不许。

## 输出末尾必须带

> 政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。

## 硬规则

- 出现筹划建议表述（节税/避税/怎么分摊更划算）→ 不许输出，必须删除
- 引用政策数字无来源与日期 → 不许输出，必须补上或删除数字
- 最终申报提交一律由用户本人在官方渠道亲手完成，不代办
