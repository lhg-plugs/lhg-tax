# /lhg-tax:checklist —— 申报材料清单

用户输入在 `$ARGUMENTS` 中（清单目录，缺省为当前目录）。

> 合规声明：**政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。**

## 流程（加载 `lhg-tax-checklist` 全程指导）

1. 读入收入构成清单 + 扣除项清单（没有就先提示跑 `/lhg-tax:tax`）。
2. 按材料四类生成清单：身份与基础信息 / 收入凭证 / 扣除凭证 / 申报辅助，
   每项标已备 / 待备 / 不适用，待备的写清去哪里补。
3. 时间节点：专项附加扣除年度确认期、年度汇算办理期、预约/错峰、更正申报，
   全部加"以当年官方公告为准"。
4. 办理渠道：个人所得税 App / 自然人电子税务局 / 办税服务厅，
   明确"由用户亲手办理，不代办"。
5. 末尾附提交前五问核对。

## 输出末尾必须带

> 政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。

## 硬规则

- 不登记身份证号、银行卡号等敏感信息
- 不编造 App 操作路径，不确定的指引看官方帮助
- 时间节点不许写死绝对日期（除非同时写清来源与核对日期）
