# /lhg-tax:deductions —— 专项附加扣除梳理

用户输入在 `$ARGUMENTS` 中（家庭情况描述，可空，空则逐项询问）。

> 合规声明：**政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。**

## 流程（加载 `lhg-tax-deductions` 全程指导）

1. 七项逐项过，不跳项：3 岁以下婴幼儿照护、子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人。
2. 每项标适用 / 不适用 / 待确认；待确认的写清"需要确认什么、去哪里确认"。
3. 适用项登记佐证材料（有 / 无 / 部分），材料不全的进易漏项提醒。
4. 输出 `扣除项清单.md`（用 skill 第 6 节模板）。

## 输出末尾必须带

> 政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。

## 硬规则

- 默认不写具体扣除金额；用户追问金额时必须同时写清来源与核对日期
- 不说"选哪项更划算""怎么分摊更省税"——筹划建议红线
