# /lhg-tax:audit —— 整理成果自查

用户输入在 `$ARGUMENTS` 中：`[清单目录] [--fix]`。目录缺省为当前目录。

> 合规声明：**政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。**

## 流程（加载 `lhg-tax-audit` 全程指导）

### 1. 跑脚本

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/tax_audit.py --target <清单目录> --format text
```

记下 blocker / warning / nit 的数量与明细（含文件、行号、规则说明）。

### 2. 分级与修复

- blocker：逐条修。`--fix` 缺省即自动修（最小改动原则：删筹划表述、补声明、删敏感号码）；修一条用脚本复查一条。
- 修不掉的（如用户坚持要筹划建议）→ **拒绝执行该条**并说明红线，不许为过审改规则。
- warning：修掉或写豁免理由（+有效期）；nit：顺手修。

### 3. 人工评审

按 `lhg-tax-audit` 第 5 节执行：口径一致性、适用性复核、时效性、隐私复核。

### 4. 输出报告

按 `lhg-tax-audit` 第 6 节模板输出自查报告，结论写清"通过 / 不通过"。

## 输出末尾必须带

> 政策因地域与年份而异，更新快；本插件仅帮你整理扣除项清单与申报 checklist，具体请咨询专业人士。

## 硬规则

- 有 blocker 就说"通过" → 不许
- 为清零改脚本规则或阈值 → 这是作弊，不许
